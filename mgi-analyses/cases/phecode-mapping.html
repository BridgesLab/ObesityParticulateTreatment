Comparing PheCodes to ICD Codes

Author

Dave Bridges

Published

November 7, 2024

There was a differnce in case counts with our classification of pneumonia cases and the data on PheWeb.

After asking the data office learned this information

We used the PheWAS package in R PheWAS/PheWAS: The PheWAS R package to create the phenotype cases and controls. This package mappings ICD9 and ICD10 codes to broader phenotypes called “phecodes.” We used a minimum code count of 1 (i.e. an individual only had to have one of the ICD codes to be considered a case for the phenotype.) You can see which ICD codes map to each phenotype using the Phecode Map v1.2. The two phenotypes you are interested in correspond to phecodes 480.1 and 480.11. The PheWAS package also applies exclusion ICD codes when determining controls – both phenotypes (480.1 and 480.11) exclude individuals with phecodes 480-488.99 from the control group. Additional details on phenotyping can be found in section 4 of our pheweb white paper: PH_MGI_Freeze6_PheWeb

Purpose

To compare phecode-ICD9/10 mapping between our codes and the Phecodes and figure out if we have all the pertinent cases

Data Entry

ICD Code Data

These were obtained by inspecting the ICD codes and mapping them as bacterial or viral pneumonia.

library(readr)
library(readxl)
library(dplyr)
diagnosis.datasheet<- 'Pneumonia ICD9 and ICD10 Codes.xlsx'
icd.data <- mapped.diagnoses <- bind_rows(
  read_excel(diagnosis.datasheet, sheet="ICD9") %>% rename(ICD=1),
  read_excel(diagnosis.datasheet, sheet="ICD10", skip=1) %>% rename(ICD=1))%>% 
  select(ICD,Type)

bacterial.diagnoses <- filter(mapped.diagnoses, Type=="Bacterial") %>% pull(ICD)
viral.diagnoses <- filter(mapped.diagnoses, Type=="Viral") %>% pull(ICD)
other.diagnoses <- filter(mapped.diagnoses, Type=="Other") %>% pull(ICD)

We had used 42 ICD9 and ICD10 codes in our analyses.
